# PHOTO -> DETECT TEXT -> COPY -> SEARCH

Kamera dibuat seperti alur Google Lens untuk tulisan:

1. FOTO
   Ambil satu foto secara manual.

2. DETEKSI TULISAN
   OCR membaca semua tulisan pada foto setelah foto diambil.

3. PILIH / EDIT TULISAN
   Hasil OCR ditampilkan sebagai teks yang bisa dipilih/diedit.
   Untuk kode eMMC, spasi dan karakter yang salah OCR dapat diperbaiki.

4. COPY TULISAN
   Salin teks yang dipilih atau seluruh hasil OCR.

5. SEARCH
   Cari teks yang dipilih. Prioritaskan kode/part number eMMC.
   Jika tidak ada di database lokal, lanjutkan pencarian web.

Kamera tetap:
- tap-to-focus
- zoom vertikal
- flash
- tombol foto di atas navigation bar
- tanpa Target IC
- tidak melakukan OCR terus-menerus
