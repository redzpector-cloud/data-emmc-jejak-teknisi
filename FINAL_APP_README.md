# Grade eMMC – Jejak Teknisi (Final App)

Fitur utama:
- Beranda modern: pencarian, Voice Search, Scan eMMC, Tambah/Edit.
- Kamera manual: FOTO & BACA, zoom +/- dan flash toggle, tanpa Target IC.
- OCR ML Kit setelah foto diambil.
- Database lokal + Grade + Kapasitas.
- Riwayat scan.
- Pengaturan voice dan zoom awal.
- Jika kode tidak ditemukan, tersedia pencarian web berdasarkan kode + eMMC + datasheet.

Build:
`gradle :app:assembleDebug --no-daemon`
